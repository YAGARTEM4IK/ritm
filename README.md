# Ритм — студенческий помощник

Бесплатный браузерный MVP на HTML, CSS и JavaScript. Без регистрации и серверной части.

## Запуск
1. Распакуйте архив.
2. Откройте `index.html` в современном браузере.
3. Нажмите «Добавить задание» и внесите свои задачи.

Для публикации в интернете загрузите три файла (`index.html`, `styles.css`, `app.js`) в статический хостинг, например GitHub Pages.

## Возможности
- Добавление, редактирование и удаление заданий.
- Предмет, дедлайн, оценка времени, приоритет и первый маленький шаг.
- Автоматическая оценка риска по сроку, объёму и приоритету.
- Режим «Что делать сейчас?» с рекомендацией следующего задания.
- Фильтрация, поиск и отметка выполнения.
- Сводка по нагрузке и диаграмма часов на ближайшие семь дней.
- Локальное сохранение через LocalStorage.

## Важные ограничения MVP
- Данные сохраняются только в текущем браузере и профиле устройства; синхронизации между устройствами нет.
- Если очистить данные сайта/браузера, список может быть удалён. Не очищайте хранилище, если хотите сохранить задания.
- Оценка риска — простая эвристика, а не гарантия того, что студент успеет или не успеет.
- Для работы нужен современный браузер с поддержкой JavaScript и LocalStorage.
- Шрифты загружаются из Google Fonts; при отсутствии интернета используются системные запасные шрифты.
